# SQL Server – Relational Database Design

## Project Overview

This academic project demonstrates the design of a relational database for managing customers, employees, products, suppliers, training courses, and sales orders.

The schema was developed using SQL Data Definition Language (DDL) and includes 11 interconnected tables.

## Technologies Used

- Microsoft SQL Server
- SQL / T-SQL
- ERwin Data Modeler (original academic model)
- dbdiagram.io (ER diagram visualization)

## Database Design

The schema demonstrates:

- Primary and foreign key constraints
- Composite primary keys
- One-to-many relationships
- Many-to-many relationships using junction tables
- Self-referencing foreign keys
- Referential integrity
